# 0.2.0-rc.1 — Web／Python 架構預發行版

[English](0.2.0-rc.1.md)

本版將產品整理為 React Web 前端與獨立 Python 後端。Release 對應 `codex/feature-python-backend` 的指定提交，不表示已合併到 `main`。這是預發行版；下列驗收限制仍適用。

## 主要更新

- 正式前端使用 Nginx，後端為非同步 Python API，移除舊 Node Gateway／Electron 產品程式。
- 目錄分為 `frontend/`、`backend/`、`data/`、`models/` 與 `deploy/`；環境變數分開管理，預設前端 5173、後端 8787。`npm run dev` 同時啟動兩端。
- Compose 同時啟動前後端；K8s 採前端 1 Pod、完整後端 2 Pods，共享 PostgreSQL／MinIO／Redis，部署前先執行 migration。
- 登入統一顯示 NT 與密碼，保留舊資料內部相容性。管理員聲紋共享採可信部門與明確核准。
- 翻譯支援 `data/jargon/jargon_en.csv` 的 `jargon`、`az_jargon_listen`，逐請求依原文命中術語並填入 `{glossary}`，檔案不變時重用解析快取。
- 正常收音維持 **3 秒／250ms**；顯示合併的句號分行門檻由 **24 字放寬到 40 字**，保留明確邊界、換人、凍結群組與既有長度限制。4 秒收音實驗已撤回。
- 導覽圖示統一配色／線條與動態狀態，支援鍵盤焦點及減少動態效果。

## 可靠性與效能

錄音本機 OPFS 提交與網路上傳分開；持久化 ACK 後才前進與清理，支援有限重試、跨重載恢復、不可變遠端分塊與錄音完成／刪除競態保護。網路上傳慢不再直接占住本機寫入佇列。

Python 加入有界非同步模型連線池、小型 ASR 記憶體路徑、提早 admission gate、短 SQL 交易與分批冪等清理。每 Pod 獨立 exporter 在 API 之外產生指標快照；Grafana／Server-Timing 區分模型往返、請求排隊及瀏覽器呈現。

Playwright 支援本機 Chrome／Edge／Chromium fallback；瀏覽器測試會清理自己的程序樹，避免已通過卻因殘留子程序逾時。中英文文件、目錄入口、Docker 建置參數、worker／連線預算與重現方式已同步。原始實驗與中間輸出留本機忽略路徑，只提交整理後結果與可執行測試。

## 驗證結果與已知限制

- 前端型別、架構、54 項單元測試與正式建置通過。Python 已記錄完整回歸 84 通過、1 跳過；部署 Web／雙 Pod／監控及錄音保存流程通過。
- 歷史容量基線：500 個不同測試 NT、600 秒、每人每 3 秒一條 ASR→翻譯鏈，100,000 條完成、零 HTTP 錯誤／重試／排程丟棄，500 份錄音共 9.6GB 回讀 SHA256 一致並清理。
- **每 2 秒的極限條件未通過**；同步瀏覽器翻譯 P90 **3.023 秒**，未達嚴格低於 3 秒的目標。UI／文件更新後未重新執行 500 人壓測。
- ASR 與翻譯 mock 各 500ms。容量結果不等於 500 個實體瀏覽器、真實模型計算、WAN 或所有背景工作同時滿載。
- Chrome 600 秒阻塞上傳測試完整恢復 58,754,560 bytes、307 次提交，無壓力暫停；96kHz／30 倍即時測試回讀 115,200,000 bytes。磁碟失敗、配額耗盡仍可能保護性暫停，不保證無限緩衝。
- 2026-10-26 npm／Python 套件稽核為零已知漏洞；不含作業系統套件，不是未知或未來漏洞保證。
- 臨時本地 Whisper 已完成測試並下線，權重與測試環境已移除；沒有改成常駐正式 ASR。H100／H200 GPU 尚未實機驗證。

## 升級與重現

先備份資料庫、錄音物件、設定及原認證密鑰。使用新的分離環境檔，既有私有檔不要被 example 覆蓋；兩個後端必須共用原密鑰與儲存。完整後端映像使用 `audio` target，frontend build 需提供 `NPM_REGISTRY`。升級 schema 不會恢復已刪資料。
