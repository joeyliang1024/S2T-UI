# 舊紀錄手動补救（2026-10-11）

舊紀錄若沒有失敗步驟，刷新圖示會開啟補救選項，不呼叫模型。使用者可選擇完整重新辨識、重新翻譯、說話者辨識或重試儲存。摘要仍在摘要頁操作。

完整重新辨識建立新音訊／逐字稿版本（音訊沿用），保留原版本；中途成功的範圍會保存，重試只補剩下範圍。讀取音訊失敗時也保留完整辨識意圖。翻譯保留原文、更新譯文，失敗保留舊譯文與失敗步驟。每次點擊執行一次，不自動循環。

驗證：TypeScript、production handler 測試、session recovery 測試、i18n、真實 React 瀏覽器搭配隔離模擬 API。未呼叫真實模型。瀏覽器測試證實舊紀錄選擇翻譯可恢復，開啟選項不送請求。handler 測試覆蓋完整 ASR 原版本保留、第一個 chunk 失敗／音訊讀取失敗後再次重試、文字型紀錄翻譯與 metadata-only 儲存。

部署：8787；K8s 保持 2 Gateway、2 audio-worker、2 ingress，Gateway 使用 `s2t-stress:20261011-legacy-recovery-final`。此變更為前端操作流程，未重跑 100 人壓測。
