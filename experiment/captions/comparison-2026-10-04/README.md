# 五分鐘即時字幕比較回放

保存於 2026-10-04。此頁是獨立實驗結果回放，不會呼叫 ASR／翻譯服務，也不會修改正式程式。

## 開啟方式

在本目錄啟動靜態伺服器：

```sh
python3 -m http.server 58755 --bind 127.0.0.1
```

瀏覽器開啟 <http://127.0.0.1:58755/subtitle-replay.html?results=final>。也可直接開啟 HTML；若音訊載入受瀏覽器限制，請使用上述方式。

兩側先選相同實驗，對照「現況字幕列」與「獨立顯示合句」；選不同實驗則可比較實際事件到達時間。五分鐘音訊 `audio-5min.mp3` 必須與 HTML 放在同一目錄，事件資料已內嵌於頁面。

## 內容與限制

- `字幕實驗報告.md`：比較方法、結果、速度門檻與建議。
- `核對案例.md` 與短音訊：供聽音核對的分歧案例。
- CSV／JSON：數值、速度驗收與原始事件。
- `實驗重跑說明.md`：原實驗套件的重跑说明；本目錄保存回放與結果，沒有包含完整實驗工具套件。

參考文字尚未人工校對，差異率不是正式 CER。回放保存的是獨立實驗結果，不代表後續正式畫面的實作已經重新量測。素材只涵蓋指定影片前五分鐘旁白；音訊來自使用者提供檔案，保存於本機供本次核對使用。
