# 五分鐘即時字幕比較

保存於 2026-10-04。本目錄是獨立實驗的結果記錄，不呼叫 ASR／翻譯服務，也不會修改正式程式。

## 內容

- `字幕實驗報告.md`：比較方法、結果、速度門檻與建議。
- `核對案例.md`：供聽音核對的分歧案例與各方法原文。
- `實驗重跑說明.md`：原實驗的交付與重跑流程說明。

比較分兩種呈現：「現況字幕列」與「獨立顯示合句」的列數對照，以及不同實驗之間的實際事件到達時間差異。數值以報告內的表格保存。

## 限制

參考文字尚未人工校對，差異率不是正式 CER。記錄保存的是獨立實驗結果，不代表後續正式畫面的實作已經重新量測。素材只涵蓋指定影片前五分鐘旁白；音訊來自使用者提供檔案，僅供當次核對使用。
