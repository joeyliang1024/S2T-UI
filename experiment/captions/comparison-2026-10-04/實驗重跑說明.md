# 實驗交付與重跑

先打開 outputs/subtitle-replay.html，音訊檔需放在同一資料夾。
outputs/字幕實驗報告.md 包含結果、速度門檻、反例與限制。

work/ 內為獨立實驗工具，未修改 S2T-UI。
目前工具預設讀取 /Users/liangzhiquan/Desktop/S2T-UI 的既有依賴及 .env。
不包含金鑰，不安裝依賴、不部署，也不改寫專案。

若在相同電腦重跑（會再次呼叫已設定的模型）：
  python3 work/build-normalization.py
  node work/probe.cjs
  node work/experiment.cjs selftest
  node work/integrity.cjs
  node work/experiment.cjs run screen-baseline normal baseline 60
  node work/experiment.cjs screen
  node work/experiment.cjs formal-a
  node work/format-probe.cjs
  node work/experiment.cjs formal-b overlap300

probe 會從原始 MP3 解碼五分鐘 PCM；本套件的 128 kbps 聽音 MP3 只供回放，
不是原始推論 PCM。正式測試按真實時間輸入，單轮五分鐘，另有尾段排空時間。
screen、formal-a、formal-b 對已存在結果會跳過；重跑需使用新的名稱或新的隔離資料夾。
定稿表只納入字元一致、受限對齊的 LocalAgreement 原型；兩個早期版本是除錯資料。
正常檔重跑為兩次觀察，快／慢候選各一次，沒有人工標準答案、沒有正式 CER。

如需換電腦重跑，先調整腳本內 repo/runtime 的絕對路徑。
快／正常／慢比較的 8 個核心模組在期間雜湊一致；同期外部專案变更列在報告中。
