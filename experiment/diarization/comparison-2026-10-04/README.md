# 長時間講者分離獨立實驗

正式程式未修改。實驗僅讀取專案 `tmp/` 的本機素材與現有模型；替代模型在獨立 work 目錄執行，沒有將錄音送到遠端。

## 查看結果

- `研究與實驗報告.md`：研究、比較結果、適用範圍與修正順序。
- `research.md`：架構候選、研究推論與第一手來源。
- `核對案例.md`：依參考標註自動選取的改善與退步案例，尚未逐例人工聽音。

即時短測以每 20 ms 真實時間餵入官方原生 stream，量的是 frame／機率／segment 結果可取得時間，不是 ASR／UI 延遲。

## 重跑與隔離

實驗在與專案正式程式隔離的獨立目錄執行。原專案素材位於 `/Users/liangzhiquan/Desktop/S2T-UI/tmp/voxconverse`；替代模型權重與 runtime 沒有打包進專案 experiment，需按研究報告的官方來源取得並核對 SHA256。不同模型依序執行，不並行爭用 CPU。工具讀取 production 模組，後續 production 版本若改變，結果不能假定與本輪相同。

68 分鐘壓測是同一真實錄音重複四次的控制實驗，不是自然長會議；完整結果列於 `研究與實驗報告.md`。

較大講者快取壓測：以官方 C ABI 保持同一 stream，僅將 v3-offline 的 spkcache_frames 由 264 改為 528，壓測回到 3 群、DER 9.51%（原配置 22.92%），重跑輸出完全相同。這不是自然一小時中文會議驗收。
